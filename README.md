# Сайн байна уу, намайг Нурлан Тиелжан гэдэг 

Би backend хөгжүүлэлт, DevOps болон full-stack бүтээгдэхүүн хөгжүүлэлтэд төвлөрч буй програм хангамжийн инженер.

Шаардлага тодорхойлох, client-ийг API-тай холбох, өгөгдөлтэй ажиллах, service-үүдийг container болгох болон deployment автоматжуулах замаар суралцдаг.

## Онцлох ажлууд

- **[BO Zar](https://github.com/nurlan1234nur/bo-zar)** — NestJS, PostgreSQL, React, React Native бүхий зарын платформ.
- **[NUM TMS](https://github.com/Binderya0623/NUM-TMS-26)** — 12 service-тэй системийн CI/CD, Docker Compose, Nginx болон VPS deployment.
- **[NUM Hospital](https://github.com/NUM-HOSPITAL-V1)** — service integration, ICD-10 хөгжүүлэлт, CI/CD болон AWS/Terraform туршилт.
- **[Nous](https://github.com/nurlan1234nur/nous)** — Express, MongoDB, Socket.IO бүхий real-time web/mobile app.
- **[Imposter](https://github.com/nurlan1234nur/imposter-game)** — гурван хэлтэй installable PWA party game.
- **[ToteType](https://github.com/nurlan1234nur/tote-type)** — Казах Төте жазу бичгийн дасгалын платформ.

## Технологи

`TypeScript` `JavaScript` `Java` `Node.js` `NestJS` `Express` `Spring Boot` `React` `Next.js` `React Native` `PostgreSQL` `MongoDB` `Docker` `Nginx` `GitHub Actions` `Terraform`
